☕ Starbucks Clone – Frontend UI Project

Welcome to the **Starbucks Clone** – a visually appealing and fully responsive frontend website inspired by the official Starbucks homepage. Built using **HTML, CSS, and JavaScript**, this project is designed to showcase modern UI design skills, responsiveness, and brand-inspired layout.

🔗 **Live Demo**: [https://star-bucks-own-clone.netlify.app/](https://star-bucks-own-clone.netlify.app/)

---

## ✨ Features

- ✅ Fully responsive layout (mobile, tablet, desktop)
- ✅ Custom navigation bar with logo and links
- ✅ Styled hero section and background effects
- ✅ Product showcase cards with images
- ✅ Clean, modern typography and colors
- ✅ Smooth scrolling and hover effects
- ✅ Footer with links and social icons

---

## 🛠️ Tech Stack

| Technology | Use |
|------------|-----|
| HTML5 | Page structure |
| CSS3 | Layout, animations, responsiveness |
| JavaScript | Interactivity & minor DOM updates |
| Netlify | Hosting & deployment |
